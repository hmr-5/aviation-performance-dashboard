أهم الاستنتاجات
الإجراءات التشغيلية الأرضية هي السبب الأكبر للتأخير (3 رحلات)، يليها أسباب متفرقة بواقع رحلة لكل منها.

تأخر وصول الطائرات والطواقم يسبب تأثيرًا تسلسليًا (Domino Effect) ينقل التأخير بين الرحلات طوال اليوم.
مطار الملك فهد بالدمام سجل أعلى متوسط تأخير (45 دقيقة) يليه مطار جدة.

الخطوط السعودية الأعلى في إجمالي ساعات التأخير لكثرة رحلاتها، مما يشير إلى اختناق في المناولة والبوابات.


✅ التوصيات
إضافة فواصل زمنية مرنة (Buffer Time) بين الرحلات المتتابعة لنفس الطائرة.
مراجعة عقود وإجراءات الخدمات الأرضية في الدمام وجدة لتقليل وقت تجهيز الطائرة (Turnaround Time).
